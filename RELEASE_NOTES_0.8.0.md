# Stealth 0.8.0

## Changes

- Add Simplified Chinese user interface and English/Chinese switch, automatically using the Windows display language on first launch.
- Save the language preference for the current Windows user.
- Translate menus, window details, transparency diagnostics and floating-overlay settings.
- Fix process wrapper handle disposal when refreshing the window list.
- Restore the slider display when Win32 rejects an opacity change.

## System requirements

Windows 10/11 with .NET Framework 4.7.2 or newer. The ZIP contains the built application and all accompanying dependencies. The release is not code signed.

Builds are published only after the Release configuration compiles and tests pass.
